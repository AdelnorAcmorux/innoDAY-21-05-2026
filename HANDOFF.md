# InnoDAY Handoff

## Current state

We are redesigning the internal InnoDAY site for Kontron.

## Fixed decisions

- Authentication: Microsoft 365 / Entra ID only
- Users: Kontron employees only
- Core actions:
  - propose an idea
  - comment on an idea
  - join/support a challenge
  - browse archives of past InnoDAY editions
- Idea categories:
  - Problem Solving & Brainstorming
  - Improvement & Realization
  - Experimentation & Exploration
- Reactions:
  - Fire = exciting / motivating / worth backing
  - Gear = innovative / clever / technically interesting
- Public profile: minimal only
  - first name
  - last name
  - company email

## V1 scope

Keep V1 simple and shallow:

- secure sign-in
- home page
- ideas list
- idea detail
- create idea
- archives
- profile page
- comments
- Fire / Gear reactions
- join challenge

## Out of scope for V1

- rich public profiles
- direct messaging
- complex approval workflows
- heavy gamification
- aggressive duplicate detection
